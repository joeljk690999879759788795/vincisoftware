how does this work
this simple tool works by cheking a folder for a index.html for displaying it as a native app

1 code your project in html and call the file index.html

2 place the app.py in the same folder make shure python and dependenies are installed to install dependeies type: pip install PyQt5 PyQtWebEngine

3 enjoy

optional: ompile to exe : type pip install pyinstaller and then pyinstaller --onefile --noconsole --add-data "index.html;." app.py
